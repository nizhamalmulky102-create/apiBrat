# 🩷 Brat Text Generator API by Ikyyy

API ini menghasilkan gambar teks "brat" bergaya lucu untuk digunakan di bot WhatsApp atau proyek lain.

## 🚀 Cara Deploy di Render
1. Upload folder ini ke GitHub.
2. Masuk ke [https://render.com](https://render.com)
3. Pilih “New Web Service”
4. Hubungkan ke repo ini.
5. Pilih branch utama (main/master)
6. Render akan otomatis menginstal dependensi dan menjalankan `npm start`.

✅ Setelah aktif, API bisa diakses seperti ini:
```
https://namaprojectmu.onrender.com/api/brat?text=IkyyyStore
```

## 🧩 Contoh Integrasi ke Bot WhatsApp
```js
await lenwy.sendMessage(msg.key.remoteJid, {
  image: { url: 'https://namaprojectmu.onrender.com/api/brat?text=IkyyyStore' },
  caption: "🩷 Generated by Ikyyy Brat API!"
}, { quoted: msg });
```
